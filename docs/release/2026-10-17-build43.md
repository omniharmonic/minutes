# Minutes build43: transcript find and simpler controls

## Included

- Search inside a transcript: highlighted occurrences, count, previous/next navigation, Unicode-aware matching and scrolling to distant matches. Library-wide search remains separate.
- Folder toolbar Edit replaced with an Organize icon. Custom folders expose swipe/context deletion with confirmation; existing meetings remain Unfiled. Rename remains in the context menu. Automatic filing preference is in Settings on both platforms; manual choices remain protected.
- Removed the redundant More menu beside Share. iPhone provides a direct meeting-view picker and Share menu; moving a meeting is available from its folder label and library context menu.
- iPhone import is a direct toolbar action. Mac import remains in library actions and File → Import.
- Saved audio has a contextual Regenerate from Recording action with confirmation. This calls the existing audio processing pipeline (transcript, speaker analysis and automatic completion). Regenerate Summary continues to use existing transcript/notes. No silent destructive reinterpretation of summary regeneration.
- Mac preserves the build42 header safe-area fix.
